# 猫猫方块解密

微信小游戏《猫猫方块》的棋盘识别和解密。给一张截图，或让手机画面实时投到电脑上，程序会找出猫在哪些格子。

格子大小和截图分辨率都不写死。换手机、关卡变大、格子变小，都可以重新量出来。

## 规则

棋盘是 N 行 N 列，一共 N 种颜色、N 只猫。

- 每一行恰好一只猫
- 每一列恰好一只猫
- 每种颜色恰好一只猫
- 猫和猫不能挨着，上下左右和四个斜角都不行

有多套都说得通的摆法时，会在同一张图上用不同颜色的编号标出来。某一格同时属于方案 1 和方案 3，就并排画 `1` 和 `3`。只有一套时，格子上画「猫」。

## 环境

- Windows 10 或更新版本
- Python 3.8 及以上
- 依赖：

```cmd
pip install opencv-python numpy pillow
```

实时窗口用的是 Python 自带的 tkinter，不依赖 OpenCV 的弹窗。装成 `opencv-python-headless` 也可以。

## 用截图解密

把截图放在这个目录下，可以一次传多张：

```cmd
python solve_cats.py 截图1.jpg 截图2.png
```

每张图会生成两个结果：

| 文件 | 内容 |
| --- | --- |
| `原名_识别.jpg` | 蓝框标出每一格，中间是颜色名 |
| `原名_解密.jpg` | 标出猫的位置；多套方案时用编号区分 |

命令行会打印棋盘尺寸、测到的格子边长和间距，以及每一套方案的行列。行列从 1 开始，第 1 行是最上面一行，第 1 列是最左边一列。

## 手机画面自动解密

电脑不连进游戏内部，只看手机投过来的画面。看到完整棋盘就会解密，开局空白或局中已有猫/叉都可以。同一局颜色不变时只算一次；过关后出现新棋盘会自动再解。

### 1. 手机投屏

手机和电脑连同一个 Wi-Fi，不要用访客网络。

小米系统自带的「投屏」是投到电视上的，这个脚本用不上。请在手机上安装开源应用 [ScreenStream](https://github.com/dkrivoruchko/ScreenStream/releases/latest)，用局域网 MJPEG 模式。

1. 安装包用文件管理打开。若系统拦截未知来源，允许这一次安装。
2. 打开 ScreenStream，模式选 **Local（局域网 / MJPEG）**。
3. 点开始，录屏提示选「立即开始」。通知栏要留着它。
4. 记下屏幕上的地址，例如 `http://192.168.31.131:8080`。
5. 电脑浏览器打开这个地址，能看到手机画面即可。
6. 小米容易把后台应用杀掉。到「设置 → 应用设置 → ScreenStream」，省电策略改为无限制，并允许后台活动。

浏览器页面可以关掉，手机会省一些流量。不关也能用。

### 2. 启动解密窗口

```cmd
python watch_phone.py http://192.168.31.131:8080
```

如果 ScreenStream 里设了数字密码：

```cmd
python watch_phone.py http://192.168.31.131:8080 --pin 1234
```

会弹出标题为「猫猫方块解密」的窗口。

- 先停在棋盘画面（开局空白或局中已有标记都可以），等猫的位置标出来。
- 局中识别时，窗口标题会带「局中」。
- 过关后下一局的棋盘出现，会自动解密新的一局。
- 手机不在棋盘界面，且还没有解过任何一局时，窗口提示打开棋盘。
- 按 `Q`、`Esc`，或直接关掉窗口，即退出。

这个窗口只在电脑上显示结果，不会替你在手机上点格子。

## 文件

| 文件 | 作用 |
| --- | --- |
| `solve_cats.py` | 从图片识别棋盘并解密，也可被实时脚本调用 |
| `watch_phone.py` | 连接 ScreenStream，在电脑上持续显示结果 |

## 说明

- 画面边缘需要还能看到游戏的浅色背景。只裁棋盘中间一小块时，识别可能不准。
- 教程小图和底部按钮会被丢掉，只保留最大的那块方阵。
- 最多列出 8 套方案。超过 8 套时，图上只画前 8 套，并在命令行说明还有更多。
- 实时解密看的是棋盘格子颜色。开局空白和局中已有猫/叉都可以；有标记时从格子边缘取底色。
